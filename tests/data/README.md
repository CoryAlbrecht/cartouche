# Test datasets

Small, repository-tracked copies of the datasets the test suite opens, so tests run from any clean checkout (CI included) without the workspace `test/files/` directory.

Generated by `npm run generate:test-data` (`scripts/generate-test-data.js`) from the full datasets in the workspace `test/files/`. Every feature, FID, attribute and layer name is preserved; only geometry detail is reduced (topology-preserving simplification and coordinates rounded to 1e-5°). Feature counts and attribute-driven assertions therefore match the full datasets. Exact geometry values do not, so don't assert on them.

| File | Source |
| --- | --- |
| `ne_10m_lakes.*`, `ne_10m_lakes_north_america.*`, `ne_10m_rivers_lake_centerline_scale_rank.geojson`, `ne_10m_coastline.*` | [Natural Earth](https://www.naturalearthdata.com/) 1:10m extracts (public domain) |
| `timeline_level_0.gpkg`, `timeline_level_0-3.gpkg`, `timeline_level_0_borders.*` | Cartouche timeline sample data |
| `project-4.cproj` | Workspace `test/projects/project-1/project-4.cproj`, with layer sources rewritten to the files in this directory |

Regenerate after changing the source datasets or `scripts/generate-test-data.js`.
